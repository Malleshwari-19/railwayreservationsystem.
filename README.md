#  Railway Reservation System

## Project Overview

The Railway Reservation System is a console-based application developed using Java. It allows users to log in, view available trains, book seats, cancel reservations and check their booking details.

This project was developed as part of my Java programming practice to understand object-oriented programming and core Java concepts.

##  Features

- **User Login:** Allows registered users to log in using their username and password.
- **Forgot Password:** Allows users to reset their password using their registered email.
- **Train Listing:** Displays available trains with their source and destination.
- **Seat Booking:** Allows users to select a train and book a seat.
- **Booking Cancellation:** Allows users to cancel an existing reservation.
- **View Booking:** Displays the user's current booking details.
- **Seat Availability:** Checks seat availability before confirming a booking.
- **Logout:** Allows users to securely exit their login session.

##  How to Run the Project

**Prerequisites:**
- Java Development Kit (JDK)
- Any Java IDE (VS Code, Eclipse or IntelliJ IDEA)

**Steps:**

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in your Java IDE.

3. Compile the Java file:

   ```bash
   javac RailwayReserationsystem.java
   ```

4. Run the application:

   ```bash
   java RailwayReserationsystem
   ```
